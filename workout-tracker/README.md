# 💪 운동 트래커 PWA

개인 운동 기록과 인바디 데이터를 관리하는 프로그레시브 웹 앱입니다.

## ✨ 주요 기능

### 📝 운동 기록
- 3가지 루틴 지원: 하체 / 등 / 가슴어깨
- 운동별 무게, 세트, 회, 코멘트 기록
- 날짜별 기록 관리

### 📊 인바디 측정
- 체중, 골격근량, 체지방률 기록
- 시간에 따른 변화 추이 그래프
- 이전 측정값과 비교

### 📈 통계 및 시각화
- 인바디 변화 그래프 (체중/골격근/체지방 탭별 보기)
- 운동 분포 차트 (루틴별)
- 월별 운동 달력
- 운동별 중량 추이

### 🔥 Firebase 통합 (NEW!)
- **데이터 안정성**: 브라우저 캐시 삭제, 시크릿 모드에서도 안전
- **다중 기기 지원**: 폰, 태블릿, PC에서 동일한 데이터 접근
- **실시간 동기화**: 클라우드 백업으로 데이터 보존
- **무료 사용**: Firebase 무료 티어로 충분 (월 1GB)

## 🚀 시작하기

### 옵션 1: Firebase 사용 (권장 ⭐)

Firebase를 사용하면 데이터가 안전하게 보관되고 여러 기기에서 접근할 수 있습니다.

1. **Firebase 설정** (10분)
   - [FIREBASE_SETUP.md](./FIREBASE_SETUP.md) 가이드를 따라 진행
   - Firebase 프로젝트 생성
   - Firestore 데이터베이스 생성
   - 웹 앱 등록 및 구성 정보 복사

2. **설정 정보 입력**
   - `js/firebase-config.js` 파일 열기
   - Firebase 구성 정보 붙여넣기

3. **앱 접속**
   - 기존 localStorage 데이터가 자동으로 Firebase로 이전됩니다
   - 이제 브라우저 캐시를 삭제해도 안전!

### 옵션 2: localStorage 사용 (기본)

Firebase 설정 없이도 바로 사용 가능합니다. (단, 브라우저 캐시 삭제 시 데이터 손실 위험)

1. [GitHub Pages](https://aeeeoong.github.io/workout-tracker/) 접속
2. 바로 사용 시작!

⚠️ **주의**: localStorage는 브라우저에 저장되므로 캐시 삭제 시 데이터가 사라질 수 있습니다. 
정기적으로 **히스토리 페이지 → 데이터 내보내기**로 백업하세요!

## 🎨 기능 상세

### 대시보드
- 총 운동 횟수, 최근 7일 운동 횟수
- 최신 인바디 정보 (체중, 골격근)
- 월별 운동 달력 (운동한 날 표시)
- 빠른 메뉴 (운동 기록, 인바디, 통계)
- 최근 운동 기록

### 운동 기록 페이지
- 날짜 선택
- 루틴 선택 (하체/등/가슴어깨)
- 각 운동별 입력
  - 무게 (kg)
  - 세트
  - 회
  - 코멘트

### 인바디 페이지
- 날짜 선택
- 체중 (kg)
- 골격근량 (kg)
- 체지방률 (%)
- 최근 기록 표시
- 히스토리 목록

### 통계 페이지
- 인바디 변화 그래프
  - 체중 탭
  - 골격근 탭
  - 체지방 탭
  - 각 탭별 Y축 자동 스케일링 (작은 변화도 잘 보임)
- 운동 분포 차트 (도넛 차트)
- 운동별 중량 추이 (개발 예정)

### 히스토리 페이지
- 전체 운동 기록 조회
- 루틴별 필터링
- 기록 삭제
- **데이터 백업**
  - 📥 데이터 내보내기 (JSON 파일로 저장)
  - 📤 데이터 가져오기 (백업 파일 복원)

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Charts**: Chart.js
- **Storage**: Firebase Firestore (클라우드) + localStorage (로컬 백업)
- **Authentication**: Firebase Anonymous Auth
- **Hosting**: GitHub Pages
