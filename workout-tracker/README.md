# 💪 운동 트래커

개인 운동 기록 및 인바디 추적을 위한 PWA (Progressive Web App)

## ✨ 주요 기능

### 📝 운동 기록
- **3분할 루틴 지원**: 하체 / 등 / 가슴어깨
- **상세 기록**: 기구별 무게, 세트, 렙, 코멘트
- **맞춤 운동 목록**:
  - 하체: 브이스쿼트, 레그프레스, 레그익스텐션, 레그컬, 어브덕션, 어덕션
  - 등: 랫풀다운, MTS rows, 아이소 랫풀다운, 어시스트 풀업, 오버헤드 프레스
  - 가슴어깨: 체스트 프레스, 플라이, 복근, 케이블 푸시다운, 어시스트 딥

### ⚖️ 인바디 추적
- 체중, 골격근량, 체지방률 기록
- 이전 측정과 자동 비교
- 변화량 시각화

### 📊 통계 및 시각화
- 인바디 변화 추이 그래프
- 운동별 중량 증가 추세
- 운동 부위별 분포 차트
- 최근 7일 운동 통계

### 💾 데이터 관리
- 로컬 저장 (LocalStorage)
- JSON 내보내기/가져오기
- 데이터 백업 및 복원

## 🚀 사용 방법

### 1. GitHub Pages 배포

```bash
# 현재 위치에서 workout-tracker 폴더를 GitHub Pages로 배포
# aeeeoong.github.io 저장소에 푸시
```

### 2. 웹 브라우저에서 접속

```
https://aeeeoong.github.io/workout-tracker/
```

### 3. 아이폰에서 앱처럼 사용하기

1. 사파리에서 접속
2. 공유 버튼 (⬆️) 클릭
3. "홈 화면에 추가" 선택
4. 앱 아이콘이 홈 화면에 추가됨! 🎉

## 🎯 사용 시나리오

### 운동 루틴 (3일 + 1일 휴식)
```
월요일: 하체
화요일: 등
수요일: 가슴어깨
목요일: 휴식
금요일: 하체
...
```

### 기록 예시
```
날짜: 2026-07-03
루틴: 하체

브이스쿼트: 40kg × 4세트 × 15렙
코멘트: 깊이 충분, 컨디션 좋음

레그프레스: 40kg × 4세트 × 12렙
코멘트: 마지막 세트 힘듦

레그컬: 70kg × 4세트 × 12렙
코멘트: 안정적
```

## 💡 팁

### 운동 기록
- 무게를 올리지 못한 운동은 공란으로 남겨도 됩니다
- 코멘트에는 컨디션, 자세, 느낌 등을 자유롭게 적어주세요
- 증량은 2~3회 안정적으로 성공한 후에 시도하세요

### 인바디 측정
- 가능하면 같은 시간대에 측정하세요 (오전 추천)
- 운동 직후나 식사 직후는 피하세요
- 한 번의 측정보다 **추세**를 보는 것이 중요합니다
- 2주~1개월 단위로 측정하는 것을 권장합니다

### 데이터 백업
- 주기적으로 "데이터 내보내기"를 통해 JSON 파일로 백업하세요
- 백업 파일을 GitHub 저장소의 `data/` 폴더에 커밋하면 안전합니다

## 🔧 커스터마이징

### 운동 기구 변경

`js/storage.js` 파일의 `exercises` 객체를 수정하세요:

```javascript
exercises: {
  '하체': [
    '브이스쿼트',
    '레그프레스',
    // 추가 또는 수정
  ],
  '등': [
    // ...
  ]
}
```

### 색상 테마 변경

`css/style.css` 파일의 `:root` 변수를 수정하세요:

```css
:root {
  --primary: #2563eb;
  --success: #10b981;
  /* ... */
}
```
