# 7월 운동기록 (사용자 입력만)

ChatGPT 대화 「인바디 변화 분석」에서 추출. AI 답변 제외.

## 기구명 매핑 (초기 모호 표현 → AI 추정)

| 사용자 표현 | 추정 기구/운동 |
|---|---|
| 앞에서 배쪽으로 당기는 거 | 시티드 로우 (Seated Row) |
| 위에서 옆구리로 당기는 거 / 위에서 옆구리로 당기기 | 스트레이트 암 풀다운 또는 아이소 래터럴 풀다운 |
| 가슴팍에서 미는 거 / 앉아서 가슴팍에서 미는거 | 체스트 프레스 |
| 팔 벌려서 앞쪽으로 당기는 거 | 펙덱 플라이 / 리어 델트 머신 (숫자만 표시, kg 아님) |
| 어깨 드는거 / 위로 살짝 드는데 어깨아픈거 | 숄더 프레스 (오버헤드 프레스) |
| 다리 벌리고 안쪽으로 모으는 거 / 안쪽으로 오므리는 거 | 힙 어덕션 (Hip Adduction) |
| 다리 모으고 바깥쪽으로 벌리는 거 / 바깥쪽으로 | 힙 어브덕션 (Hip Abduction) |
| 어깨로 들어올리고 앉았다가 일어나는 기구 / 스쿼트 기구 | V스쿼트 (브이스쿼트) |
| 위에서 당기는 거 (양쪽 따로) | 케이블 머신 (원판 양쪽 각각, 합산 아님) |
| 위에 걸어두고 아래로 밀 | 케이블 푸시다운 (삼두) |
| 위에 달아놓고 당기는거 | 오버헤드 케이블 컬 (이두) |
| 등 안쪽 보고 앉아 손잡이 아래에서 위로, 팔꿈치 옆구리로 | 로우 머신 (핀 꽂는 방식, 시티드로우 변형) |

**헬스장:** 대전 신성동 지비짐  
**무게:** 레그프레스·V스쿼트 = 총무게. MTS Row·플라이 = 핀/숫자(kg 아닐 수 있음).
