## 🚀 임포트 방법

### 방법 1: 설정 페이지에서 임포트 (추천)

1. 앱 접속: https://aeeeoong.github.io/workout-tracker/
2. 하단 메뉴 → **설정**
3. **데이터 관리** 섹션
4. **데이터 가져오기** 클릭
5. `workout-data-import.json` 파일 선택
6. 완료! 🎉

### 방법 2: 브라우저 콘솔에서 직접 실행

앱을 열고 브라우저 개발자 도구(F12)를 연 후, 콘솔에서 아래 스크립트 실행:

```javascript
// workout-data-import.json 파일의 내용을 복사해서 fetch로 가져오기
fetch('/workout-tracker/workout-data-import.json')
  .then(res => res.json())
  .then(data => storage.importData(data))
  .then(() => {
    alert('✅ 데이터 임포트 완료!');
    location.reload();
  });
```
